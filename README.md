# ChoreQuest 🏆

A private, offline iPhone app that turns home chores into a game. Earn points for every chore you
finish, see who's winning, and keep a timestamped history — all stored on your phone, nothing online.

> Native SwiftUI · SwiftData (on-device) · iOS 17+ · zero third-party dependencies

This repository is built incrementally through reviewed pull requests. See the open PRs for what's
landing next.
